# NIS Website

A classic static ISP website for Neema Internet Solution Limited.

[![Deploy to DO](https://www.deploytodo.com/do-btn-blue.svg)](https://cloud.digitalocean.com/apps/new?repo=https://github.com/telenexus-admin/neema/tree/main)

## Files

- `index.html` - page content and structure
- `styles.css` - layout, color, responsive design
- `script.js` - mobile menu and contact form mail link
- `assets/images/` - NIS logo and website photos used across the page

## DigitalOcean Preview

This repo is ready for DigitalOcean App Platform as a static site. The deployment template is in `.do/deploy.template.yaml`.

DigitalOcean can detect the static site from the root `index.html`, or you can use the deploy button above after the code is pushed to GitHub.

## Customization Needed

Send the real business details and they can be added quickly:

- Logo
- Internet package speeds and prices
- Phone, email, WhatsApp number, and social links
- Office address
- Service areas
- Map or Google Maps embed
